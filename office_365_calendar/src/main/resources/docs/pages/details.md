
### Detail Description of Fields:

* Is All Day: This property set the meeting for all day. The values can be true or false.
* Reminder: This property is about reminding the event. The values can be 'Don't remind me' , 'At time of event' or '5 minute before'.
* Recurrence: This property is about repeating the event. The values can be 'Does not repeat' , 'Daily' , 'Weekly' . If you select daily, weekly, monthly or yearly then it is mandatory to fill all the details below according to the need.
* Recurrence Interval: This property is about time between two events. For example: If you need the event to occur every Monday then set **Recurrence interval** to 1 and **Days of week** to Monday.
* Days of Week: This property specifies that on which days of week you want the event to occur. You can give multiple days. For example: Monday or Monday and Tuesday.
* Recurrence Type: Absolute recurrence is for exact date and relative recurrence is for that day. For example: On 19th June 2023,assume it is third Monday of month. If you select absolute recurrence then it will occur exactly on 19th day of month and if you select relative then it will occur on third Monday of that month.
* Day of Month: This property  specifies that on which specific days of month you want the event to occur. For example: 2, 3 or 4.
* Repeat index: This property is only for **Recurrence** monthly and yearly. This property specifies that on which **Days of week** of month the event should occur. For example: If I need a event which should occur every third Monday then I will set days of week to Monday and repeat index to third.
* Repeat day: This property specifies that on which specific day you want to repeat the event. For example: Monday or Friday.
* Repeat Month: This property specifies that on which specific month you want to repeat the event. **Day of month** is needed. For example: June or November.
* End Recurrence: This property specifies that on which specific thing you want to end the recurrence. If you select end date then you have to enter the end date in **End Date** below or if you selected **Numbered Occurrences** then you have to give number. This number will specify the total times of occurrence will happen.
* End Date: Check **End Recurrence**
* Numbered Occurrence: Check **End Recurrence**

### Schedule Daily Recurrence Meeting:

Set the following mandatory parameters and other parameters are filled according to need:

* Start Date: Start date of recurrence.<br>
* Recurrence: Daily<br>
* Recurrence Interval: Interval between days.<br>
For example: 1 for daily, 2 for every other day.
* Days of Week: To repeat on which days in the week. Add all days for daily recurrence.<br>
For example: Monday, Thursday only.
* End Recurrence: How to end the recurrence.<br>
  * End Date: Give end date to complete recurrence on the given data.<br>
  * Numbered Occurrences: End recurrence meeting after these many recurrences.

### Schedule Monthly Recurrence Meeting:

Set the following mandatory parameters and other parameters are filled according to need:


* Start Date: Start date of recurrence.<br>
* Recurrence: Monthly<br>
* Recurrence Interval: Interval between months.<br>
  For example: 1 for all months, 2 for every other month.
* Recurrence Type: Type of Recurrence.<br>
  * Absolute Recurrence: To occur on exact date. Day of month parameter is compulsory. <br>
  For example: If start date is 21 June 2023, Wednesday then recurrence will occur on 21st day of month.<br>
  * Relative Recurrence: To occur on exact day. Repeat Day and Repeat Index parameter is compulsory. 
  For example: If start date is 21 June 2023,Wednesday then recurrence will occur on Wednesday of month.
* Repeat Month: Specifies that on which specific month you want to repeat the event.
* End Recurrence: How to end the recurrence.<br>
  * End Date: Give end date to complete recurrence on the given data.<br>
  * Numbered Occurrences: End recurrence meeting after these many recurrences.
